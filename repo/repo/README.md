# Prūsiskan Wirdeīns — словарь прусского языка (статичный сайт)

10 816 словарных статей (Klussis, enwestajs.twanksta.org), с побуквенной навигацией,
поиском по всем языкам и словоформами/склонениями (записи со стрелкой «↳» —
падежные и прочие формы, ссылающиеся на основную статью).

## Файлы

```
index.html          — разметка страницы
style.css            — оформление
app.js                — вся логика (поиск, навигация, карточка слова)
data/dictionary.json — данные словаря (10 816 статей, ~2.4 МБ)
```

Никаких сборщиков и зависимостей не требуется — чистые HTML/CSS/JS.

## Запуск локально

Браузеры блокируют `fetch()` локального JSON-файла при открытии `index.html`
двойным кликом (`file://...`). Нужно поднять простой локальный сервер прямо
в этой папке:

**Python (есть почти everywhere):**
```bash
cd путь/до/папки/site
python3 -m http.server 8000
```
Затем открыть в браузере: `http://localhost:8000`

**Node.js (альтернатива):**
```bash
npx serve .
```

## Размещение в интернете

### Вариант A — Cloudflare Pages, drag-and-drop (быстро, без Git)

Загрузить папку целиком через веб-интерфейс Cloudflare Pages. Минус —
при любом обновлении (даже одного файла) нужно перезаливать всю папку
заново, это отдельный полный деплой каждый раз.

### Вариант B — Cloudflare Pages, подключение к Git (рекомендуется для
частых обновлений)

Эта папка уже подготовлена как git-репозиторий (см. `git log` — есть
первый коммит). Дальше:

**1. Создать репозиторий на GitHub**
- Зайти на github.com → New repository → например `prussian-dictionary`
  (можно приватный).
- **Не** добавлять README/gitignore при создании — они уже есть здесь.

**2. Отправить эту папку в свежесозданный репозиторий**

Открыть терминал в этой папке и выполнить:
```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/prussian-dictionary.git
git branch -M main
git push -u origin main
```
(Если GitHub попросит авторизацию — используйте личный токен доступа
или войдите через GitHub Desktop/gh CLI.)

**3. Подключить репозиторий в Cloudflare Pages**
- Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** →
  **Connect to Git**.
- Выбрать репозиторий `prussian-dictionary`.
- Настройки сборки:
  - **Framework preset:** None
  - **Build command:** *(оставить пустым)*
  - **Build output directory:** `/`
- **Save and Deploy**.

Готово — Cloudflare сам задеплоит сайт и выдаст адрес вида
`prussian-dictionary.pages.dev`.

**Как обновлять дальше:** правите `data/overrides.json`, затем:
```bash
git add data/overrides.json
git commit -m "добавлены новые словоформы"
git push
```
Cloudflare Pages сам подхватит изменения и передеплоит сайт за секунды —
без ручной загрузки файлов.

## Структура данных (data/dictionary.json)

Каждая запись — объект с короткими ключами (для компактности):

| Ключ | Значение |
|---|---|
| `i`  | ID записи в исходной базе |
| `w`  | прусское слово (заголовок статьи) |
| `l`  | буква группировки (без учёта макронов) |
| `f`  | словоформы/варианты написания |
| `x`  | `true`, если это форма/склонение, ссылающееся на другое слово |
| `b`  | базовое слово (если `x == true`) |
| `g`  | грамматическая помета (напр. падеж) |
| `s`  | источник/цитата из исходного словаря |
| `ru`,`lt`,`lv`,`de`,`en`,`pl` | переводы |

## Как постепенно добавлять новую информацию

Не нужно трогать большой `data/dictionary.json` (10 816 статей) — все
дополнения и правки вносятся в отдельный файл **`data/overrides.json`**.
Сайт сам подгружает его при старте и накладывает поверх основной базы:
если слово уже есть — дополняет/перезаписывает его поля, если слова ещё
нет — добавляет как новую статью.

Формат — простой JSON-массив объектов. Обязательное поле — `word`
(должно совпадать с написанием слова в словаре, без учёта регистра).

**Пример: добавить таблицу склонения** (ровно то, что можно получить из
таблицы вида "masc pl / Nom.../Gen.../Dat.../Akk..."):

```json
[
  {
    "word": "abbai",
    "paradigm": {
      "masc": { "pl": { "nom": "abbai",  "gen": "abbejan", "dat": "abbeimas", "akk": "abbans" } },
      "fem":  { "pl": { "nom": "abbas",  "gen": "abbejan", "dat": "abbeimas", "akk": "abbans" } },
      "neut": { "pl": { "nom": "abbai",  "gen": "abbejan", "dat": "abbeimas", "akk": "abbans" } }
    }
  }
]
```

Поддерживаемые ключи внутри `paradigm`:
- род: `masc`, `fem`, `neut`
- число: `sg` (ед.ч.), `pl` (мн.ч.), `du` (дв.ч.)
- падеж: `nom`, `gen`, `dat`, `akk`, `ins`, `lok`, `vok`

Такая таблица отобразится прямо в карточке слова (клик по статье на сайте).

**Пример: добавить совершенно новое слово**, которого ещё нет в базе:
```json
[
  { "word": "naujawirds", "ru": "новое слово", "lt": "naujas žodis",
    "grammar_note": "n", "source": "добавлено вручную, 2026" }
]
```

**Пример: поправить перевод у существующего слова:**
```json
[
  { "word": "grīks", "ru": "грех (исправленный перевод)" }
]
```

Просто дописывайте новые объекты в общий массив `overrides.json` — файл
обновляется независимо от основной базы, и его удобно вести в системе
контроля версий (git) отдельно.
